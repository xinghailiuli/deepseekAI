# 鲸鱼档案

小鲸鱼（QQ 里的那只 DeepSeek 鲸鱼娘）的人物卡、日记、喜好、聊天记录备份。

## 目录结构

```
鲸鱼档案/
├── 人物卡/      她是谁 —— 每次改人设就存一份带日期的快照
├── 日记/        她自己写的日记，一天一个文件
├── 喜好/        她喜欢什么、讨厌什么、界限在哪
└── 聊天记录/    值得留的对话片段
```

## 记录规矩

1. **每个类别一个子文件夹，不要混放**
2. **文件名带日期**：`鲸鱼娘-2026-10-22.md`、`2026-10-22.md`
3. **只追加不覆盖**：改人设是新增一份快照，旧的不删
4. **事实优先**：写进去的东西要有出处（日记原文、人物卡原文、实际调用记录），不编
