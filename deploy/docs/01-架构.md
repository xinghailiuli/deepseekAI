## 端口表

| 端口 | 服务 | 用途 | 是否对外 |
| --- | --- | --- | --- |
| 3100 | qq-bridge 控制台 | 复读最近消息、手动唤醒、开关、审计 | 仅 127.0.0.1 |
| 3200 | bot-daemon | Minecraft 机器人状态 + `/map` 俯视图 | 仅 127.0.0.1 |
| 3205 | pcgame-service | 窗口截图/点击/按键、消消乐引擎 | 仅 127.0.0.1 |
| 6081 | SnowLuma noVNC | 扫码登录时的「看屏幕」（只需一次） | 仅 127.0.0.1 |
| 5180 | SnowLuma WebUI | 账号管理 | 仅 127.0.0.1 |
| 13000 | SnowLuma OneBot HTTP | 桥接 → 网关 | 仅 127.0.0.1 |
| 13001 | SnowLuma OneBot WS | 备用长连 | 仅 127.0.0.1 |
| 19387 | DSH 本地 API | 桥接 → 模型 | 仅 127.0.0.1 |
| 25565 | Minecraft 服务端 | 机器人进服 | 局域网 |

**原则：全部绑 127.0.0.1。** 一个都不往外开，需要远程就看 noVNC 的隧道。

## 数据落在哪

```
qq-bridge/state/
  ├─ console-token          控制台鉴权（随机串，别提交）
  ├─ bridge.log             运行日志（超过 5MB 轮转）
  ├─ tool-calls.jsonl       每次工具调用的审计流水（同样轮转）
  ├─ social-v2.json         每个会话的唤醒配置、记忆、待发原因
  └─ mode.json              当前模式：chat / closed-agent / reserved2

qq-bridge/roles/鲸鱼娘.md    角色卡（人设 + 工具用法），换个文件就是换个人
features/写作/{截图,图片}/    AI 能发的本地图，只能从这里发
features/小黑盒/audit.jsonl   发帖审计
鲸鱼档案/                     人设/日记/喜好 → git 备份
```

## 为什么分成 bridge + DSH 两层

- **bridge 管「像不像人」**：发送节奏、条间停顿、限频、白名单、审计、唤醒策略、记忆。这些东西放在模型侧不可控。
- **DSH 管「会不会做事」**：模型、工具调用、MCP 生态。
- 好处：换模型不动桥接；改人设不动代码；某个 MCP 崩了不影响聊天。

## 会话标识

统一用 `private:<QQ号>` / `group:<群号>` 作为 key。桥接、状态文件、控制台、审计日志全用这一套，
排查时 `grep 'group:123456'` 一把梭。
