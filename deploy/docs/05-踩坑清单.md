# 05 · 踩坑清单（都是真踩过的）

按「疼的程度」排。

## 1. 唤醒指令中文全变问号

`state/bridge.log` 里 `admin: ?????,????? 5 ?`，看着像唤醒了，其实 AI 收到一串问号 ——
整整半天它都在按旧习惯干活，因为**指令根本没传进去**。

PowerShell 5.1 的 `Invoke-WebRequest -Body` 不按 UTF-8 编码。修法见 `02` 文档。

## 2. 改了 MCP 白名单不生效

`qq-tool-restrict.mjs` 的 `SAFE_PREFIXES` 是**启动时加载进内存**的。
改文件 → 报 `工具不在白名单内` → 以为改错了，其实是没重启 DSH。

而且 DSH 的自动重启在本机被沙箱挡（拒绝访问），只能手动重启。

## 3. 重启 DSH 会把子进程全杀

桥接、bot-daemon、pcgame-service 全挂在 DSH 的 job object 下，DSH 一重启全掉。
所以必须有看门狗（`scripts/watchdog.ps1` + 计划任务每 3 分钟巡检）。

## 4. DSH 重启会重写 profile patch

手工加的 MCP `args` 可能被抹掉。改完先 `copy cordis.patch.yml cordis.patch.yml.bak`，
重启后 `diff` 一遍。

## 5. 截图只有半张 / 点击整体偏移

150% DPI + 非 DPI 感知进程 = 窗口矩形只有实际的一半。两个 PS 脚本都要
`SetProcessDpiAwarenessContext(-4)`。

判断方法：`pcg_click` 返回的 `clicked` 坐标如果**超出屏幕宽高**，一定是 DPI 问题。

## 6. PowerShell 脚本里的中文乱码 / 语法报错

PS 5.1 读无 BOM 的 UTF-8 会把中文当 ANSI。**所有含中文的 .ps1 必须存成 UTF-8 with BOM**。

## 7. npm 找不到

在某些环境 `npm` 不在 PATH。用绝对路径：

```powershell
node "C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js" install
```

## 8. 小黑盒存下来的图全是站点图标

三个原因叠在一起：
- 图片域名白名单漏了 `imgheybox1.max-c.com`
- 按 `.jpg` 结尾判断 URL，实际是 `?imageMogr2/format/jpg`
- 选择器漏了 `.hb-cpt__image-elem`

修法：域名后缀匹配 `.max-c.com` + URL 里含 `imageMogr2|format/jpg` + 读 `srcset` + 尺寸闸门（≥300×200）。

## 9. 小黑盒匿名抓不到正文

匿名 profile 渲染只有壳，标题变成站名。切登录态 `profile:'main'`。

## 10. 小黑盒 `ERR_NAME_NOT_RESOLVED`

TUN 模式 DNS 假 IP。修法：DoH 解析（`dns.alidns.com/resolve`）+ Chromium 参数
`--host-resolver-rules=MAP host ip`。

## 11. 收藏表情报 429「太频繁」

配置里 `sticker.collect.maxPerMinute/maxPerHour` 默认有限制，设 0 取消。
实测 4 秒收 4 张没问题。

## 12. 「QQ 一分钟只能发一张图」是假的

3 张图 6 秒发完，messageId 各不相同。别被自己写进人设的限制唬住。

## 13. prismarine-viewer 装不上

要原生 `canvas`，Node 24 + Windows 编译必挂。改成纯 Node 自己画俯视图。

## 14. Java 8 只能跑 MC 1.16.5

装 1.20 服务端会直接崩。

## 15. 模拟器切横竖屏坐标系会变

横屏时的坐标在竖屏下发会报「超出窗口范围」，必须重新截图取坐标。

## 16. 最小化窗口截不到内容

PrintWindow 对最小化窗口返回黑图。玩的时候别最小化。

## 17. 结算页卡死几分钟（最常见）

AI 打完一关 → 汇报 → 结束回合去睡 → **结算页没人点「继续」**。
看日志它是「10 秒内就汇报完了」，但画面停在那里几分钟，用户看到的就是「卡半天」。

修法两条一起上：
1. 人设明确写成「**看到结算页第一件事就是点继续，点完才允许说话**」
2. 给一个固定坐标的一键工具（`pcg_next`），不让它自己算按钮位置

## 18. 日志文件突然「消失」

桥接有轮转：`tool-calls.jsonl` 超过阈值改名 `tool-calls.jsonl.1`。
查日志时两个文件都要看，别以为数据丢了。

## 19. 唤醒被拒但日志说成功

`POST /api/socialV2/wake` 永远回 `{ok:true}`（异步投递），真实结果看日志：
- `会话繁忙，暂存唤醒原因 ...（原因=pendingWakeKey）` → 它正处于一轮对话里，唤醒排队等下次
- `原因=turn` → 模型正在思考

**判断「它到底动没动」只看 `tool-calls.jsonl`**，不要看接口返回。

## 20. 别用 process 名选窗口

按进程名抓 `msedge`，抓到的是「Edge 意外关闭，是否恢复」那个窗口，截出来的图全是恢复页。
选窗口要 **handle + 标题** 双确认。
