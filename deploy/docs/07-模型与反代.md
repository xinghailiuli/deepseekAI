# 07 · 模型与反代（Magpie）· 签到 · 看门狗扩项

这套部署的模型链路有两套来源：**反代（订阅账号）** 和 **API（按量付费）**。
默认策略：能走反代就走反代，反代全挂才用 API。

## 一、链路

```
DSH ── provider: dsh-magpie-connect / model: group/domestic
  └─ Magpie 网关 http://127.0.0.1:3425/v1  (apiKey: magpie)
       ├─ WorkBuddy AI   (OAuth: 账号 A)
       ├─ WorkBuddy      (OAuth: 账号 B)
       ├─ Codex          (OAuth: ChatGPT)
       └─ 全挂 → 桥接 fallback → deepseek-account API
```

## 二、Magpie 网关怎么起

它**不是** GUI 版 `Magpie.exe`（那个是屏幕放大工具，同名不同物）。网关在 CLI 里：

```powershell
& 'E:\11\magpie\magpie-cli-windows-amd64.exe' tui    # 前台打开时顺带 serve 3425
& '...\magpie-cli-windows-amd64.exe' web --gateway   # 无桌面环境（WSL/服务器）用这个
```

用 `tui` 时要**留着进程**：它一关，网关就没了。所以把它交给看门狗：

```powershell
# 每 3 分钟检查 3425，掉了就拉起（隐藏窗口 + 日志）
if (-not (Test-NetConnection 127.0.0.1 -Port 3425 -InformationLevel Quiet)) {
  Start-Process '<magpie.exe>' -ArgumentList 'tui' -WindowStyle Hidden `
    -RedirectStandardOutput '<log>\magpie-tui.log' -RedirectStandardError '<log>\magpie-tui.err'
}
```

## 三、四层兜底（从内到外）

| 层 | 在哪配 | 行为 |
| --- | --- | --- |
| 1 | Magpie `provider fallback` | 某个订阅额度用完/限频/宕机 → 换同体系的另一个账号 |
| 2 | Magpie 路由组 `group/domestic` | `routing=order`，按顺序试组内 5 个模型 |
| 3 | 桥接 `dsh.fallback` | 错误信息命中 quota/429/402/403 → 切 `deepseek-account`（API） |
| 4 | 看门狗 | 网关进程挂了 → 12 秒内重新拉起 |

配置命令：

```powershell
magpie provider fallback workbuddy-ai workbuddy/deepseek-v4.1-flash codex/gpt-5.6-luna
magpie provider fallback workbuddy    workbuddy-ai/deepseek-v4.1-flash codex/gpt-5.6-luna
magpie provider fallback codex        workbuddy/deepseek-v4.1-flash workbuddy-ai/deepseek-v4.1-flash
magpie group domestic            # 看组内顺序
```

桥接侧：

```json
"dsh": {
  "provider": "dsh-magpie-connect",
  "model": "group/domestic",
  "fallback": { "provider": "deepseek-account", "model": "deepseek-flash" }
}
```

## 四、WorkBuddy 每日签到

magpie 自带命令，不用碰浏览器：

```powershell
magpie accounts checkin      # ✓ 某账号 checked in today +100 · 2 天连续
```

幂等：同一天再跑会返回 `already`，不会重复领也不会报错。

做成每天自动（隐藏窗口，日志 `logs\checkin.log`）：

```
任务名 QQWhale-WorkBuddyCheckin   每天 08:05   wscript run-checkin-hidden.vbs
```

**坑**：`.vbs` 必须存 **ANSI(936)**；存成 UTF-8 with BOM 时 WSH 会静默卡死，任务状态一直显示 Running 但什么都不干。

## 五、看门狗要管的端口（六项）

```
3100  桥接            3200  MC 机器人        3205  游戏服务
25565 MC 服务器       13000 SnowLuma 容器     3425  Magpie 反代网关
```

故障演练（必做一次，确认真的会拉起来）：

```powershell
Get-Process | ? { $_.Path -match 'magpie-cli' } | % { Stop-Process -Id $_.Id -Force }
powershell -File scripts\whale-watchdog.ps1
Test-NetConnection 127.0.0.1 -Port 3425 -InformationLevel Quiet   # 期望 True
```

## 六、账号状态怎么看

```powershell
magpie accounts          # 每个订阅的额度、重置时间、fallback 关系
magpie providers         # 三个 provider 是否登录、模型数、fallback 链
magpie groups            # 路由组顺序
```

`context deadline exceeded` 表示额度查询超时（网关拿不到用量接口），**不影响调用**，只是看不到剩余量。
