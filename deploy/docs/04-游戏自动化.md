# 04 · 游戏自动化（截图 / 点击 / 模拟器 / galgame）

这套是「让 AI 真的玩」的核心。全部围绕两个脚本：

```
scripts/capture-window.ps1   PrintWindow 截图（DPI 感知）
scripts/act-window.ps1       SetCursorPos + mouse_event 点击（DPI 感知）
```

服务 `pcgame-service.mjs` 监听 3205，MCP `pcgame-mcp.mjs` 是它的门面。

## 一、两个致命细节

### 1. DPI 感知

150% 缩放下，不申请 DPI 感知的进程拿到的窗口矩形是**逻辑像素**，
结果：截图只有左上角半张、点击位置整体偏移。

```powershell
[DllImport("user32.dll")] public static extern IntPtr SetProcessDpiAwarenessContext(IntPtr v);
try { SetProcessDpiAwarenessContext(new IntPtr(-4)); } catch {}   // PER_MONITOR_AWARE_V2
```

两个脚本都必须加，否则一处对一处错，看起来像「坐标算错了」。

### 2. 坐标是「窗口内相对坐标」

```
屏幕坐标 = 窗口左上角 + 窗口内坐标
```

模型看图拿到的是窗口内像素（和截图同一坐标系），**不要**让它自己加窗口偏移量。
验证方法：`pcg_click` 的返回里有 `window:[x,y]` 和实际 `clicked:[X,Y]`，对不上就是 DPI 问题。

## 二、工具清单（pcgame 命名空间）

| 工具 | 说明 | 耗时 |
| --- | --- | --- |
| `pcg_windows` | 列所有窗口，找 handle | 0.3s |
| `pcg_capture` | 截图，图直接进模型视野 | 1.5s |
| `pcg_swap` | 一次完成「点 A → 点 B」，**默认不截图** | 4.3s |
| `pcg_swaps` | 一次走 1~6 组交换，最省时间 | 8s |
| `pcg_click` / `pcg_key` | 单点 / 按键（SPACE/ENTER/ESC/方向键） | 1.7s |
| `pcg_next` | 点「继续」进下一关，固定坐标 (383,894) | 4.2s |
| `pcg_skip` | 点掉教学弹窗，**两个高度各点两下** | 9s |
| `pcg_games` / `pcg_launch` | allowlist 里的 PC 游戏启动 | — |

### 为什么默认不截图

每张图约 1,300 token。一步一截图 = 20 步 26,000 token，还慢（19 秒/步）。
**截一次 → 算好 2~4 步 → 一次 `pcg_swaps` 发出去**，8 秒/步。

## 三、模拟器（以 MuMu 打开心消消乐为例）

```
MuMu Player 12\ nx_main\MuMuNxMain.exe   → 设备窗口 "MuMu安卓设备"
竖屏 763×1405（窗口内），棋盘 7×7，格子间距 78.5px，首格 (141,570)
```

- adb 没装也能玩：全靠窗口截图 + 屏幕点击，免 root 免权限
- 真实战绩：连过 5 关，第 1 关 142,370 / 第 5 关 135,115，全三星
- 关键：**每一步之前要看一眼棋盘**，纯靠记忆算不出掉落

### 弹窗和结算页（最浪费时间的两个地方）

| 场景 | 症状 | 解法 |
| --- | --- | --- |
| 「彩星过关」结算页 | AI 汇报完就睡了，没人点继续，卡几分钟 | **先 `pcg_next` 再说话**，别先汇报 |
| 教学弹窗 | 点「跳过引导」没反应 | 按钮高度每关不同（实测 1168 / 1208），**两个都点**，再补点棋盘中央 |
| 游戏倍速 | 动画慢，拖时间 | 按 `ESC` 打开设置，里面有 常速/快速/高速/极速 |

## 四、galgame

```
pcg_windows 找 handle → pcg_capture 看当前剧情 → pcg_click(画面中间) 或 pcg_key(SPACE) 推进
```

- 只点自己那个窗口，不碰用户正在用的窗口
- 看不到画面就先 `pcg_capture`，别盲点

## 五、自己的游戏（不依赖模拟器）

`features/小游戏/` 是纯 Node 实现的消消乐引擎 + 纯 Node PNG 画板（`features/共用/png.mjs`，手写
IHDR/IDAT/zlib/CRC32），802×698 棋盘 265ms 出图 14KB，不装任何图形库。

好处：**没有浏览器、没有 canvas、没有截图**，模型直接看渲染出来的棋盘，走一步 1 秒。
